# simulator/ (reserved)

[`docs/05-SIMULATION-ARCHITECTURE.md`](../docs/05-SIMULATION-ARCHITECTURE.md):

- the demo repository seed (`payment-service`, deterministic commits C1–C5);

- the open-loop load generator;

- the reset tooling.

It is intentionally empty in Phase 1 (foundation). Nothing here is mocked or stubbed yet.
